樹種調査判定

Excel取り込み対応版です。

使い方：
1. index.htmlを開く
2. 「樹種データの更新・管理」を開く
3. 「Excelデータを読み込む（.xlsx）」から樹高区分のExcelを選択
4. 取り込み完了後、樹種名・区分・別名①～③がこの端末に保存されます

Excelの列構成：
A列：区分（低木・中木・高木。区分が結合セルでも読み取ります）
B列：樹種名
D～F列：別名①～③

検索は完全一致、部分一致、近似検索に対応します。
Excel取り込みは外部ライブラリを使わず、現行ブラウザのZIP解凍機能を使用します。
※ブラウザのローカルファイル直接起動やPWA環境での動作は環境により異なるため、Excel読み込み機能はChrome/Edgeなど最新ブラウザで確認してください。
